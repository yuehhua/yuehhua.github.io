ISB LAB · TMU COURSE

Data Structures and Algorithms

Implementation-driven course from memory models to dynamic programming; each data structure maps to a biomedical build—ER triage queues (heaps), ward round lists (linked lists), medical-term autocomplete (tries).

GOAL—Course goal

Turn logic into algorithms that solve problems—implement every data structure yourself and build abstract structures into working systems.

MAP—Course map

M1 · W1–W4

Linear Structures & Memory

Memory models, arrays and pointers, stacks/queues and linked lists—handle memory yourself and see how data actually lives.

W4 Clinical & biomedical translation

The ward-round list

A linked-list ward-round list that grows and shrinks with every admission—insertion and deletion are just a couple of pointer updates.

M2 · W5–W7

Search & Trees

From binary search to BSTs and tries—turning “look it up” into logarithmic-time art.

W6 Clinical & biomedical translation

Medical autocomplete

How does a keyboard suggest “Taipei” in a millisecond? Build autocomplete for medical terms and genetic motifs with a trie.

M3 · W8–W13

Sorting & Dynamic Programming

Divide-and-conquer, heaps, greedy and dynamic programming—from the limits of sorting to the core of optimization.

W9 Clinical & biomedical translation

The ER triage queue

A max-heap triage queue for the emergency room, guaranteeing the most critical patient is always first in line.

M4 · W14–W16

Graph Algorithms

Traversals, topological sort and shortest paths—modeling any system that connects.

W15 Clinical & biomedical translation

Shortest paths in metabolism

Weight reactions by their energy cost and let Dijkstra find the cheapest path through the metabolic network.
