GeometricFlux.jl

Open source · official Julia ecosystem

  • Geometric deep learning
  • Graph neural networks
  • Open-source software

The geometric deep learning and graph neural network library of the official Julia ML ecosystem, Flux.jl. It unifies the message-passing and graph-network frameworks, ships an efficient compressed-sparse graph data structure, and provides 10+ graph convolutional layers on CPU and CUDA.
